# ブログ OGP バナーの背景画像

ここに置いた背景画像の上に、記事タイトル＋ブランド要素を自動で重ねて、ブログ各記事の
OGP バナー（1200×630 PNG）をビルド時に自動生成します（`/og/blog/<slug>.png`）。

## 置き方
- サイズ：**1200 × 630 px**（推奨）。多少違っても中央基準でフィットします。
- 形式：png / jpg / webp
- 文字が乗っても読めるよう、上に半透明の暗色グラデーションが自動でかかります。
  背景は「左下〜下部に文字が乗る」前提で、その辺りが極端に明るい/うるさい絵柄は避けると綺麗です。

## ファイル名でテーマを指定（記事に合わせて自動選択）
ファイル名の**先頭**を以下にすると、その種類の記事で優先的に使われます（複数可・`document-1.png` 等）。

| 先頭 | 使われる記事の例（タグ/タイトルに含む語） |
|---|---|
| `document` | 帳票 / PDF / Excel / CSV / 出力 / 印刷 |
| `search`   | 検索 / 絞り込み / 一覧 / フィルタ |
| `design`   | デザイン / 見た目 / おしゃれ / UI / 配色 / テーマ |
| `record`   | レコード / フォーム / 入力 / 詳細画面 / 目次 / フィールド / タブ |
| `data`     | 集計 / 分析 / グラフ / サマリー / ランキング / 採番 |
| `update`   | アップデート / 最新 / 新機能 / リリース |
| `general`  | 汎用（テーマに当たらない記事はここから安定的に選択） |

- テーマに当たらない記事は `general*`（無ければ全画像）から、スラッグで安定的に1枚選ばれます。
- 1枚も無い場合は `default.png`（同梱のブランドグラデ）が使われます。

## 反映
画像を追加して push すると、GitHub Actions のビルドで各記事のバナーが再生成されます。
既存記事で frontmatter に `ogImage` を明示している記事は、そちらが優先されます
（自動生成を使いたい記事は `ogImage` を書かない）。
