# バナー右側の「貼り込み画像」（前景）

バナーは「**背景＝og-bg の9枚（暗い）＋ 左テキスト ＋ 右の貼り込み画像（ここ）**」で合成されます。
右の画像は、記事ごとに Gemini で生成 → 共有 → KIZUNA Works 側でリネームしてここに配置 → 自動で合成。

## 置き方・命名
- **記事専用**：`<記事スラッグ>.png`（例 `kintone-cyouhyou-pdf-output.png`）→ その記事で最優先採用。
- **テーマ共通**：`document* / search* / design* / record* / data* / update* / general*` → 同テーマの記事で使い回し。
- 形式：**透過PNG推奨**（暗い背景の上に重なるため、明るめ・白基調が映える）。正方形〜やや横長。
- 画像が無ければ右側は背景のみ（テキストだけのバナーになる）。

## 生成（Gemini）共通スタイル
```
透過PNG（背景は完全に透明）のフラットなベクターイラスト1点。
配色は白を基調に、ネイビー(#1B3A6B)とグリーン(#2E8B2E)のアクセント。
濃い紺色の背景の上に重ねて使うので、明るめ・はっきりしたコントラストで。
モダンでクリーンなフラットデザイン、立体感は控えめ。被写体は中央にまとめ、周囲に余白。
文字・数字・ロゴは一切入れない（no text, no letters, no numbers, no watermark）。実在UIは描かない。
正方形（1024×1024）・高解像度・背景透過。
```
共通スタイルの後に、記事内容に合うモチーフを続ける（モチーフは記事ごとに KIZUNA Works 側が指定）。

## 反映
ここに置いて push すると CI ビルドで該当記事のバナーに自動合成されます。
ローカル確認は `npm run build` 後に `dist/og/blog/<slug>.png`。
