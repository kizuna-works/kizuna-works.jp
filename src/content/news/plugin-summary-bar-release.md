レコード一覧画面のヘッダーに、**合計・平均・最大・最小・件数の集計カードを並べて表示**する新プラグイン「**集計サマリーバー for kintone**」v1.0.0 を公開しました。絞り込みに連動して即時に再集計するので、グラフ画面に移動せず「今この一覧の数字」をひと目で把握できます。

## 主な機能

- **一覧ヘッダーに集計カードを常設** — 合計・平均・最大・最小・件数の 5 種類を表示
- **絞り込みに連動して即時再集計** — 一覧の絞り込み・ソートに合わせてカードが自動更新
- **「表示中／絞り込み全件」をトグル切替** — 現在ページだけ／絞り込み条件の全レコードをワンクリックで切替（上限件数で API 負荷を保護）
- **一覧ビューごとに別のカード構成** — 一覧ごとに種類・順番・色を別々に設定（最大 10 枚）
- **集計値による条件付き色分け** — 固定値や別フィールドの集計値と比較して配色をテーマで切替（例：売上合計が目標売上合計を上回ったら緑）
- **段組みレイアウト** — カードごとに表示段（1〜3段）を指定して 2 段・3 段表示
- **配置・文字寄せ・整形** — 左寄せ／中央／右寄せ／均等フル幅、集計値の文字寄せ、プレフィックス／サフィックス（¥ / 円 / % など）
- **淡色テーマ8種＋個別配色上書き** — バー全体の配色テーマとカード単位の色指定
- **GAS・外部サービス不要** — kintone 完結。プラグインアップロードのみで導入完了

「絞り込んだ結果の合計や件数を、グラフ画面に移動せず一覧の上でそのまま確認したい」という声に、kintone 完結で応えられます。
