Chrome 拡張機能「KW App Exporter for kintone」を **v1.2.0** にアップデートしました。これまでの設定情報に加えて、そのアプリが**何で動いているか**——追加されているプラグインと、適用されている JavaScript / CSS カスタマイズ——まで書き出せるようになりました。

## v1.2.0 で新しくできるようになったこと

- **プラグイン**：追加されているプラグインの名前・バージョン・有効/無効・プラグイン ID を一覧化
- **JavaScript / CSS カスタマイズ**：適用範囲（すべてのユーザー／管理者だけ／適用しない）と、PC・モバイル別の読み込み順・ファイル名 / URL を出力
- **ファイルの中身を ZIP に同梱**：「ファイルの中身も同梱する（ZIP で出力）」を選ぶと、アップロード済みの JavaScript / CSS ファイルを実体ごと保存。読み込み順が分かる連番フォルダーと、適用範囲を書いた README が付きます

## 不具合の修正

- **アプリアクセス権限・フィールドアクセス権限が、HTML と Excel で内容が空欄になっていた不具合**を修正しました。利用者の方からご指摘をいただいたものです（JSON と Markdown での出力は影響を受けていません）
- あわせて、アクセス権限に「アプリ管理」「下位組織への継承」の列を追加し、アプリの作成者やユーザー種別を日本語で表示するようにしました

## 既存ユーザーへの影響

これまでの 8 カテゴリはそのまま使えます。新しい 2 カテゴリは既定で有効になっていますので、不要な場合はポップアップのチェックを外してください。Chrome ウェブストア経由で自動的に v1.2.0 へ更新されます。

なお、**ゲストスペース内のアプリは対象外**です。開いた場合はその旨を表示するようにしました。
