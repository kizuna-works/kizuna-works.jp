kintone プラグイン「**Box連携 for kintone**」**v1.0.0** を公開しました。プレミアムプラグインの第22弾です。

## 添付は、Box へ。kintone にはリンクだけ。

kintone のディスク容量は 1 ユーザーあたり 5GB です。図面・写真・見積書・契約書と添付が増えるほど上限が近づき、**容量を買い増すか、古いレコードから手で消していくか**の二択になりがちです。

このプラグインは、レコードに添付されたファイルを **Box の指定フォルダへ転送**し、kintone には**リンクだけ**を残します。転送に成功したファイルは kintone から削除できるので、ディスク使用量を抑えながら、ファイルの実体は普段お使いの Box で一元管理できます。

## 主な機能

- **レコード単位のフォルダを自動生成** — レコード番号や顧客名などのフィールドを組み合わせた命名ルールを作れます。空のフィールドは前後の区切り文字ごと省くので、`__` のような不格好なフォルダ名になりません
- **差分検知** — ファイル名とサイズを突き合わせ、同じファイルを二重に送りません。同名で中身が違うファイルは、別名で追加するか、新しいバージョンとして上書きするかを選べます
- **転送後の kintone 側削除** — 全件の転送成功・Box 上での実在確認・リンクの書き戻し成功がそろったときだけ削除します。1 件でも失敗したら 1 件も削除しません（既定はオフ）
- **共有リンクの作成** — Box の共有リンクを別のリンクフィールドへ入れられます
- **フォルダの中身の表示** — レコード詳細画面に、Box フォルダの中身を一覧で表示します
- **サブテーブル内の添付にも対応** — 行ごとに処理し、行ごとにリンクを返します
- **一覧からの一括転送** — 過去分の回収に使えます（プレミアム）

## 中継サーバーを経由しません

ファイルは**利用者のブラウザから Box へ直接**送られます。当社のサーバーを通ることはありません。Box 側には、お客様の Box に作る連携用のアプリ（サービスアカウント）を使い、**招待されたフォルダにしか触れません**。

手動で転送するボタンは、置き場所（4か所）・ラベル・形（角丸・ピル・四角・枠線・アイコン）・ボタンと文字の色を設定画面で選べます。設定画面の見本で、仕上がりを確かめながら決められます。

## 事前に Box 側の準備が必要です

お客様の Box に連携用のアプリを作り、Box 管理者に承認していただき、転送先のフォルダに招待する準備が必要です。会社の Box のご契約（または Box 開発者アカウント）でお使いください。個人の無料アカウントでは使えません。手順は準備手順ページにまとめています。
