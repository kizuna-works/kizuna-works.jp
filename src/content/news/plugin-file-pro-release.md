kintone プラグイン「**添付ファイル Pro for kintone**」**v1.0.0** を公開しました。KIZUNA Pro プラグインです。

## 添付ファイルの操作を、1つのプラグインで

添付ファイルプレビュー・添付ファイルアイコン表示・添付ファイル出力・画像圧縮・PDF編集アシストの5つの機能を、**1つのプラグイン・1つの設定画面**で使えます。

## 添付ファイル Pro だけの機能

- **このレコードの添付** — 詳細画面で、テーブルの中も含む全部の添付を並べて、見る・PDFに書き込む・ZIPで保存・画像を圧縮ができます
- **添付の容量** — 一覧で、いまの絞り込みの添付の合計と、大きいレコード、圧縮でおよそ減る量を確認できます。設定でオンにしたときだけ、画像の一括圧縮もできます
- **ZIP で画像を縮小** — ZIP に入れる画像だけを縮めます。レコードの画像は変わりません
- **添付を検索** — 一覧の［添付を検索］で、添付のファイル名と、ファイルの中の語から探せます。結果はサムネイルのカードで並び、押すとプレビューで開きます。語を空にすると、絞り込みの添付をすべて並べるギャラリーになります
- **PDFにまとめる** — PDF と画像を選んで並べ替え、1つの PDF にします。ダウンロードするか、レコードの添付欄に保存できます。ブラウザの中で組み立てるので、ファイルは外部へ送られません
- **ファイル名をそろえる** — 添付欄ごとに名前の型を決めると、保存したときに、新しく添付したファイルの名前を型どおりに付け直します
- **添付のきまり** — 添付欄ごとに、使える形式・1ファイルの上限・点数の上限を決め、添付したときにすぐ確かめます
- **まとめ** — 添付欄ごとに、5つの機能が効いているかを1つの表で確認できます。対象欄も、まとめてそろえられます

## 単品のプラグインを使っているアプリにも

同じアプリに単品のプラグインが入っているときは、その機能は単品が動きます。単品の設定は、添付ファイル Pro の設定画面の［単品の設定を読み込む］で引き継げます。
