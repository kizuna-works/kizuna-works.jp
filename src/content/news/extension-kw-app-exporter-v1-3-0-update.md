Chrome 拡張機能「KW App Exporter for kintone」を **v1.3.0** にアップデートしました。利用者の方からいただいたご要望に対応した版です。

## v1.3.0 で新しくできるようになったこと

- **カテゴリーのエクスポート**：アプリに設定されているカテゴリーを、階層・親カテゴリー・並び順つきで HTML / JSON / Excel / Markdown に出力します。ポップアップのエクスポート対象に「カテゴリー」が加わりました
- **ポップアップの高さを調整**：v1.2.0 で項目が増えて縦に長くなり、「エクスポート実行」ボタンまでスクロールが必要になっていました。余白を整理し、全項目を表示した状態でもスクロールなしで押せるようにしました

## ご利用にあたって

カテゴリーの取得には、kintone のアップデートオプション「検討中の新機能」で「カテゴリーの設定を取得または更新するREST API」を有効にしている必要があります。有効でない環境や、カテゴリー機能を使っていないアプリでは、その旨を出力に記載し、ほかの項目は通常どおり出力します。

## 既存ユーザーへの影響

これまでの 10 カテゴリはそのまま使えます。新しい「カテゴリー」は既定で有効になっていますので、不要な場合はポップアップのチェックを外してください。Chrome ウェブストア経由で自動的に v1.3.0 へ更新されます。
