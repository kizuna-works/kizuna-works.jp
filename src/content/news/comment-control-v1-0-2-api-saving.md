kintone プラグイン「**コメントコントロール for kintone**」を **v1.0.2** にアップデートしました。kintone の API リクエスト数を節約するため、一覧コメントバッジの取得の仕組みと設定方法を変更しています。

## 今回のアップデート内容

- **API リクエストの大幅な節約** — これまでは、対象の一覧を開くたびに、表示中のレコード全件（最大100件）のコメントを自動取得していました。1回一覧を開くだけで表示件数と同じ回数のコメント取得 API を実行するため、kintone の API リクエスト数（1アプリ1日あたりの上限）を短時間で大きく消費していました。今回のアップデートで、**コメントの取得は「件数バッジにマウスを乗せたときだけ」**に変わり、**一覧を開くだけでは API を消費しません**。バッジのホバーでコメントを全文プレビューする機能はこれまでどおり使えます。
- **自分宛メンションの一覧色分けを任意オプション化** — 自分宛メンションのあるレコードを一覧で色分けする機能は、一覧を開いた時点でコメントを取得する必要があるため、**設定画面の任意オプション（初期状態オフ）**に変更しました。オンにした場合でも、**コメントのあるレコードのみ・最大20件まで**に取得を絞り、無駄なリクエストを抑えます。API を消費したくない場合はオフのままご利用ください（ホバーでの全文プレビューはオフでも利用できます）。

## 既存ユーザーの方へ

最新版（v1.0.2）をダウンロードし、kintone のシステム管理 → プラグインから**上書きアップロード**するだけで適用できます。既存の設定はそのまま引き継がれます。
