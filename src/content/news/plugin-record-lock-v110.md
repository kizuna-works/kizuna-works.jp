kintone プラグイン **[レコードロック for kintone](/plugins/record-lock/)** を **v1.1.0** にアップデートしました。無料でご利用いただけます。

## 「本人捺印」をロックできるようになりました

[ユーザーオートフィル for kintone](/plugins/user-autofill/) の**本人捺印**は、編集モードにしなくてもクリックだけで押印・取り消しができます。手軽な反面、**承認プロセスが終わったレコードの印影を、誤ってクリックして取り消してしまう**という声をいただきました。

v1.1.0 では、ロック対象に<strong>「本人捺印」</strong>を追加しました。ロック中は「捺印」ボタンを押せなくし、自分が押した印影のクリック（取り消し）も受け付けません。**押印済みの印影と押印日はそのまま表示され、印刷にも出ます。**

ロック範囲（レコード全体／フィールド指定）とは独立した設定なので、「レコードの項目は編集できるが、捺印だけは触らせない」という使い方もできます。

なお、止まるのは画面での操作です。CSV 読み込みや REST API 経由の書き換えは止まりません。

## 2 件の不具合を修正しました

- **除外グループ・除外組織が効いていなかった問題**を修正しました。v1.0.5 まで、除外リストにグループや組織を入れても、その所属メンバーはロックされたままでした（除外ユーザーの個別指定だけが働いていました）。**グループや組織で除外していたアプリでは、更新後に設定どおり除外されるようになります**ので、意図した設定になっているかご確認ください。
- **ロック範囲が「レコード全体」のとき、詳細画面の編集・削除ボタンが隠れていなかった問題**を修正しました。保存自体はこれまでも止まっていましたが、編集画面に入って入力したあとで弾かれる状態でした。v1.1.0 では「レコードを編集する」と［⋮］の「レコードを削除」が最初から表示されません。

## 更新方法

最新版をダウンロードして、kintone の「システム管理 → プラグイン」から**上書きアップロード**してください。プラグインIDは変わらないため、既存の設定はそのまま引き継がれます。

[レコードロック for kintone のページを見る →](/plugins/record-lock/)
