kintone プラグイン「**添付ファイルプレビュー for kintone**」を **v2.5.0** にアップデートしました。

## ← → キーを、ファイルの切り替えにもページ送りにも使えます

設定画面の「モーダルの操作とデザイン」に **「← → キーの役割」** を追加しました。プレビュー中の ← → キーを、次のどちらに使うかを選べます。

- **ファイルの切り替え**（既定）
- **ページ送り**（複数ページの PDF）

選ばなかった方は **Shift + ← →** で使えます。**PageUp・PageDown キー**は、設定に関係なく常にページ送りです。

ページ送りは、最初と最後のページで止まります。次のファイルへは進みません。「キーボード操作を有効にする」がオフのときは、役割を選べません。

## 文字の入力欄への入力を邪魔しにくくなりました

パスワード付き PDF のパスワード欄などに入力しているときと、Alt + ← などブラウザの操作のときは、プレビューがキーを受け取りません。

## 設定を保存したあとの移動を改善しました

設定を保存したあと（キャンセルしたときも）、「アプリの設定」画面へ戻ります。そのまま［アプリを更新］を押せます。

## 更新方法

kintone のプラグインは自動更新されません。製品ページから v2.5.0 をダウンロードし、**システム管理 → プラグイン**から上書きアップロードしてください。保存済みの設定はそのまま引き継がれ、v2.4.0 から更新した場合は「ファイルの切り替え」のまま、今までと同じ動きです。
