kintone プラグイン「**添付ファイルプレビュー for kintone**」を **v2.3.0** にアップデートしました。

## 関連レコード一覧の添付ファイルもプレビューできます

これまで、レコード詳細画面の「関連レコード一覧」に表示された**参照先アプリの添付ファイル**は、クリックするとダウンロードになっていました。中身を確認するには参照先のレコードを開き直す必要があり、案件に紐づく見積書・工程表・議事録などを続けて見たいときに手間がかかっていました。

v2.3.0 では、**関連レコード一覧のファイル名をクリックすると、そのまま全画面のモーダルで中身が開きます**。

![kintone のレコード詳細画面 — 「案件管理」レコードの関連レコード一覧「提出書類」に、参照先アプリの添付ファイル（見積書・工程表・仕様書・議事録）がファイル名リンクで並んでいる状態](/images/file-preview-reftable-01.png)

![添付ファイルプレビューのモーダル画面 — 関連レコード一覧から開いた PDF（工程表）が、表・工程のバー・注記までそのままの体裁で全画面表示されている状態](/images/file-preview-reftable-02.png)

- 対象は**レコード詳細画面**の関連レコード一覧です（編集画面・印刷画面・一覧画面は従来どおりダウンロードになります）。
- **参照先アプリ側にプラグインを設定する必要はありません。** 関連レコード一覧を置いているアプリの設定だけで動作します。
- ページ送り（「次へ」）で表示した行にも自動で適用されます。
- 設定画面の「プレビュー対象フィールド」には「**関連レコード一覧名 ＞ 項目名**」で表示されます。1 つも選択していない場合は自動的に対象になります。

## 更新方法

kintone のプラグインは自動更新されません。製品ページから v2.3.0 をダウンロードし、**システム管理 → プラグイン**から上書きアップロードしてください。設定の再登録は不要です。
