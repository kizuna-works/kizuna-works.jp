kintone プラグイン **[クイックサーチ for kintone](/plugins/quick-search/)** を **v1.3.0** にアップデートしました。お客様からいただいたご要望をもとにした改善です。

## 関連レコード一覧の中身でも検索できます

顧客アプリで「この案件はどの顧客だったか」「この担当者の会社はどこか」を探すとき、これまでは案件アプリや担当者アプリに移って探し、元のアプリで探し直す必要がありました。

設定画面の［検索対象フィールド］で、**関連レコード一覧に表示している項目**（案件名・担当者名・活動内容など）も選べるようになりました。キーワードが**いずれかの関連レコード**に含まれていれば、そのレコードが検索結果に出ます。

- 自アプリの項目と組み合わせて、AND / OR で検索できます。
- 関連レコード一覧の絞り込み条件も、そのまま反映されます。
- 選べるのは、関連レコード一覧の「表示するフィールド」に設定したテキスト系・選択肢系の項目です。
- 連携先アプリを別に検索しないので、検索のたびに API リクエスト数が増えることはありません。

## 閲覧できない項目は、自動で検索対象から外します

フィールドのアクセス権や連携先アプリの閲覧権限で、その利用者が見られない項目は、利用者ごとに自動で検索対象から外すようにしました。外した項目は検索バーの横に「一部の項目は検索対象外」と表示され（クリックで理由を表示）、ほかの項目で検索を続けられます。

キーワードが長すぎて kintone で検索できないときも、検索する前にお知らせするようにしました。

## 更新の手順

最新版を kintone システム管理 →「プラグイン」→「読み込む」から上書きアップロードしてください。プラグインIDは変わらないため、**各アプリに保存済みの設定はそのまま引き継がれます**。これまでの検索の動きは変わりません。関連レコード一覧の項目を検索したいときは、プラグインの設定画面で項目を選んで保存し、アプリを更新してください。
