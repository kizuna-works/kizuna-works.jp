kintone プラグイン「**シート編集 for kintone**」を **v1.5.2** にアップデートしました。グリッドの上で**チェックボックス・複数選択のセルを、その場で選んで保存できる**ようになりました。

## 選択を確定する OK ボタンが表示されます

チェックボックスと複数選択のセルをダブルクリックすると、選択肢の一覧が開きます。**v1.5.1 までは、この一覧の下にある OK ボタンが背景色を失って見えない状態**でした。選択肢にチェックは付けられるものの確定する手段が分からず、セルに値が入らないままになっていました。v1.5.2 では、設定した配色どおりに OK ボタンが表示されます。

![シート編集 for kintone v1.5.2 — 「タイムシートへ転記」列のセルを開いたところ。選択肢「転記」「未選択」の下に、設定した配色の OK ボタンが表示されている](/images/sheet-edit-after-07.png)

## 閉じ方が2通りになりました

- **ほかのセルをクリックして閉じた場合も、選んだ内容が反映されます**（これまでは破棄されていました）。列の絞り込みメニューと同じ動きに揃えました
- **Esc キー**を押すと、選択を反映せずに閉じます

影響があるのは**チェックボックスと複数選択の列だけ**です。文字列・数値・日付・ドロップダウン・ラジオボタンなどの列は、これまでどおり編集できます。

最新版は kintone のシステム管理 →「プラグイン」→「読み込む」から上書きアップロードしてください。プラグイン ID は変わらないため、保存済みの設定（表示フィールド・絞り込み条件・配色など）はそのまま引き継がれます。
