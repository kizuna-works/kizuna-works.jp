kintone プラグイン「**添付ファイルプレビュー for kintone**」を **v2.4.0** にアップデートしました。

## プレビュー中の PDF・画像を、その場で印刷できます

これまでは、添付ファイルを印刷するにはいったんダウンロードし、PDF ビューアや画像ソフトで開き直す必要がありました。

v2.4.0 では、PDF と画像のプレビュー中に、ツールバーの **「印刷」** でブラウザの印刷画面が開きます。

![添付ファイルプレビューのモーダル画面 — 契約書の PDF を表示中。ツールバーに表示中のページ番号「2 / 3 ページ」と「印刷」ボタンが並んでいる](/images/file-preview-print-01.png)

- **PDF は元のファイルのまま全ページ**を印刷できます（プレビューの「先頭 50 ページ」の制限はかかりません）。印刷するページの範囲は、印刷画面の「ページ」で指定します。
- PDF のプレビュー中は、ツールバーに **表示中のページ番号**（「2 / 3 ページ」）が出ます。見ているページだけを印刷したいときに使えます。
- **画像**は用紙に収まるように印刷し、横長の画像は横向きで印刷します。
- パスワード付きの PDF は、パスワードを入力して表示したページ（先頭 50 ページまで）を印刷します。
- Excel・Word・PowerPoint・テキストは印刷の対象外です。

## 印刷ボタンを表示する人を指定できます

設定画面に「印刷ボタン」の項目を追加しました。印刷ボタンは既定で表示されます。**表示する人を、ユーザー・組織・グループで指定**することもできます（名前やコードで絞り込んで、候補から複数選べます。何も選ばなければ全員に表示）。

![添付ファイルプレビューの設定画面 — 「印刷ボタン」の項目。表示する人をユーザー・組織・グループのタブから選び、選んだ「グループ Manager」「組織 営業部」が並んでいる](/images/file-preview-print-02.png)

ダウンロードボタンは全員に表示されるため、印刷を禁止する機能ではありません。

## 更新方法

kintone のプラグインは自動更新されません。製品ページから v2.4.0 をダウンロードし、**システム管理 → プラグイン**から上書きアップロードしてください。保存済みの設定はそのまま引き継がれ、印刷ボタンは全員に表示されます。
