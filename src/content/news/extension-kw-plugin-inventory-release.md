kintone を長く使っていると、アプリごとに追加したプラグインや JavaScript／CSS カスタマイズが増えていきます。「このファイルはまだ使っているのか」「テスト中の設定が残っていないか」を確かめるには、アプリの設定画面を1つずつ開くしかありませんでした。

Chrome 拡張機能「KW Plugin Inventory for kintone」は、ドメイン内の全アプリのプラグインとカスタマイズを読み取り、1つのレポートにまとめます。

- どのアプリにも使われていないプラグイン、無効のまま残っているプラグインなど、見直しが必要なものを10種類の区分で「要対応」に一覧表示します
- 外部のサイトからスクリプトを読み込んでいるアプリと、その読込先が分かります
- 設定を変えたまま「アプリを更新」していないプラグイン・カスタマイズを見つけます
- KIZUNA Works 製プラグインに新しい版があれば、最新版と製品ページへのリンクを表示します
- 結果は Excel・CSV・HTML などのファイルに保存でき、印刷画面から PDF にもできます
- 読み取りのみで kintone の設定は変更せず、取得した情報は外部に送信しません

cybozu.com 共通管理者が実行するとドメイン内の全アプリ、それ以外の方はアプリ管理権限のあるアプリが対象です。ゲストスペースにも対応しています。完全無料です。
