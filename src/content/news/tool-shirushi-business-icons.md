kintone のアプリアイコンをブラウザだけで作れる無料Webツール「Shirushi」に、事務・ビジネス向けのアイコンを **68種** 追加しました。内蔵アイコンは全部で **249種** になりました。

## 追加したアイコン

| 分類 | アイコン |
|---|---|
| 書類・帳票 | 印鑑・承認印・請求書・見積書・納品書・発注書・起票・書類検索・機密文書・差し戻し・書類一式・バインダー・台帳・議事録・付箋・署名・FAX・スキャン・郵便（〒）・名刺 |
| 人・組織 | 握手（商談・契約）・営業・部署・採用・退職・人事評価・点検・組織図 |
| 業務管理 | ワークフロー・カンバン・工程表・ステップ・方針・休暇・締切・タイムカード・工数 |
| オフィス | デスク・会議室・ホワイトボード・掲示板・社内報・相談・受付・整理券 |
| お金・成果 | 予算・レジ・振込・KPI メーター・ランキング |
| 法務・安全 | 法務・証明書・セキュリティ・パスワード・ヘルメット・救急箱 |
| 物流・製造 | 工場・在庫・検品・ルート |
| IT | テレワーク・キーボード・ネットワーク・開発・不具合・履歴 |
| 移動 | 宿泊・駐車場 |

「アイコン」タブの検索欄に「請求書」「納期」「押印」「テレワーク」などの日本語を入れると、該当するアイコンが絞り込まれます。色と大きさは自由に変えられ、文字や絵文字と組み合わせて透過PNGで書き出せます。
