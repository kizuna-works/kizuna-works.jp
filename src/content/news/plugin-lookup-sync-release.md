**ルックアップ元（マスター）**のレコードを更新すると、その値を**ルックアップでコピーしている参照先アプリの既存レコード**を自動で追従更新する新プラグイン「**ルックアップ自動同期 for kintone**」v1.0.0 を公開しました。kintone 標準のルックアップは、取り込んだ後にマスターを直しても過去のコピー値は古いまま残りますが、本プラグインが**マスターの変更を検知して参照先を自動で最新化**します。「プレミアムプラグイン」シリーズの一つです。

## 主な機能

- **マスター更新で参照先を自動追従** — マスターの会社名・単価などを変更して保存すると、それを参照している受注・在庫・請求などの既存レコードのコピー値を自動更新
- **参照先を自動スキャン検出** — このマスターを参照しているルックアップフィールドをドメイン内から自動検出。コピー項目（フィールドマッピング）も自動取得で手入力不要
- **自動・手動モード** — 対象ごとに、保存後すぐ反映する自動と、確認ポップアップで選んで実行する手動を選択
- **サブテーブル対応** — サブテーブル内のルックアップにも対応し、該当行ごとに追従更新
- **今すぐ全件同期** — 導入前からの既存レコードや反映漏れも、参照先アプリの全レコードをワンクリックで一括最新化（件数無制限）
- **kintone 完結** — 同期はすべて自ドメインの kintone REST API で完結。業務データを外部へ送信しません。ゲストスペースにも対応
