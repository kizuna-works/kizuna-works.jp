レコードに添付した**画像・PDF・Excel・Word・テキスト**を、ダウンロードや画面遷移なしで**その場のフルスクリーンモーダル**で確認できる新プラグイン「**添付ファイルプレビュー for kintone**」v1.0.0 を公開しました。一覧・詳細のファイル名をクリックするだけで開き、中身確認のためのダウンロードや詳細画面への往復を減らせます。

## 主な機能

- **ファイル名クリックでフルスクリーンプレビュー** — レコード一覧・詳細でファイル名リンクをクリックすると、画面全体のモーダルで表示
- **形式別レンダリング** — 画像（jpg/png/gif/webp/svg/bmp）／PDF（複数ページ）／Excel（列幅・セル結合・色・罫線・配置を再現＋**グラフも再現描画**）／Word（ページ体裁を再現）／テキスト（txt/csv/json/md/log・**文字コード自動判定**で Shift_JIS にも対応）
- **複数ファイルの連続閲覧** — 同じ添付欄のファイルを「前へ／次へ」・サムネイル・左右キーで続けて閲覧
- **モーダルサイズ 大／中／小** — 初期サイズを設定でき、プレビュー中も切替（記憶）
- **大容量ガード・ダウンロード** — 大きいファイルは確認ダイアログ。モーダルからダウンロードも可能
- **非対応形式は素通し** — pptx・xls・doc・zip 等は kintone 標準どおりダウンロード
- **kintone 完結・ファイルの中身は外部送信なし** — ファイルはブラウザ内だけで表示。表示ライブラリのみ当社サーバーから SRI（改ざん検知）付きで読み込み、改ざんリスクのある第三者 CDN は利用しません

見積書・請求書・契約書の PDF や、現場写真・物件写真などを頻繁に確認する業務で効果を発揮します。既存の「**添付ファイルアイコン表示**」（一覧で添付の有無・種別をアイコンで可視化）と組み合わせると、「アイコンで察して、クリックで開く」流れがスムーズになります。
