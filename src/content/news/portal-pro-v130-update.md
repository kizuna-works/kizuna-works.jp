[ポータル Pro for kintone](/plugins/portal-pro/) を **v1.3.0** にアップデートしました。

## アプリ一覧を改善しました

- スペースのポータルに置くアプリ一覧で、［表示するアプリ］から［このスペースのアプリ］を選べます
- スペース向けの画面に新しく置いたときの既定は、そのスペースのアプリだけです。すでに置いてあるアプリ一覧は、今までどおりすべてのアプリを表示します
- アプリのアイコンは、指定しなくても、kintone のアプリに設定したアイコン（画像・プリセット）がそのまま出ます

## ポータルの編集画面を改善しました

- アプリのタイルをドラッグして、並び順を決められます
- 並び順は「管理者の指定順」に切り替わります。分類ごとの表示では、同じ分類の中で入れ替えられます。元に戻すも使えます

## ポータル用JSの登録の案内を改善しました

- ［公開］のあと、ポータル用JSが未登録または古い版のときは、「あと1つ手順があります」のダイアログで、ダウンロードと登録の手順をご案内します
- 編集画面の上部の帯でも知らせます。設定画面の初期設定にも、ダウンロードと登録の手順を加えました
- kintone 全体のカスタマイズは公式の API で変えられないため、登録はこれまでどおり kintone のシステム管理で行います（自動にはなりません）

## 更新方法

最新バージョン（v1.3.0）を製品ページからダウンロードし、kintone のシステム管理 → プラグインから上書きアップロードしてください。そのあと、設定画面の［ポータル用JS］から PC 用・スマホ用の JS をダウンロードし直し、kintone システム管理の［JavaScript / CSS でカスタマイズ］に登録し直してください。アプリ一覧とアイコンの改善はポータル用 JS に入っているため、登録し直すまでは変わりません。
