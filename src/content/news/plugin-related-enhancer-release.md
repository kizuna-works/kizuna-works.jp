レコード詳細画面の**関連レコード一覧**を、集計・見た目・検索/ソートでまとめて強化する新プラグイン「**関連レコード拡張 for kintone**」v1.0.0 を公開しました。kintone 標準の関連レコード一覧は「表示するだけ」で合計や件数の集計ができませんが、本プラグインが**カーソルAPIで参照先を全件取得して集計カードを一覧の上に表示**し、見た目の調整やその場検索・並べ替えまでまとめて実現します。「プレミアムプラグイン」シリーズの一つです。

## 主な機能

- **集計カード** — 関連レコードの合計・平均・最大・最小・件数を算出してカード表示。条件（AND/OR）で絞り込み、条件別カードを複数並べて比較でき、閾値を超えたら背景色を警告色に
- **非表示フィールドの集計** — 関連レコード一覧の「表示するフィールド」に入れていない数値・計算フィールドも集計対象に選択可能（APIトークン不要）
- **サブテーブル展開集計** — 参照先アプリのサブテーブル内フィールドを、行の絞り込み条件で絞ってから合計・平均などを算出
- **集計結果の書き込み保存** — 集計値を自アプリの数値フィールドへ自動／手動で保存。保存した値は一覧の絞り込み・集計・CSV出力にそのまま使えます
- **見た目カスタマイズ** — ゼブラ表示・行ホバー・フォントサイズ・列の表示/非表示・列幅（省略記号でクリップ）・ヘッダーの背景色/文字色
- **検索・ソート・簡易フィルタ** — 一覧にインライン検索バー、列ヘッダークリックでソート、列ごとの簡易フィルタ（すべてブラウザ内で完結）
- **横断ボード** — 複数の関連レコード一覧の集計を、フォームのスペース要素1箇所にまとめて表示
- **kintone 完結** — 集計・表示はすべて自ドメインの kintone REST API で完結。業務データを外部へ送信しません

## ご利用プラン

無料プランでも**1つの関連レコード一覧に集計カード・見た目・検索**をお試しいただけます。非表示フィールドの集計・サブテーブル展開集計・集計結果の書き込み保存、および対象数の無制限化と広告非表示は、**プレミアム年間サポーター**（年額 ¥16,500・税込）で解放され、販売中の全プラグインも利用できます。
