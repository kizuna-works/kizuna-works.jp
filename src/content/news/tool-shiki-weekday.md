無料ツール「[Shiki（kintone計算式ジェネレーター）](/tools/Shiki.html)」に、曜日を出すレシピを追加しました。

**まず訂正です。** 公開時（2026年9月13日）の「実機で『できない』と確かめたこと」の表で、**「曜日は計算式では取得できない。プラグインか JavaScript が必要」と記載していましたが、これは誤りでした**。ご利用者の方からご指摘をいただき、サイボウズ公式の FAQ「[日付の値に応じて曜日を表示する方法を教えてください。](https://kintone-faq.cybozu.co.jp/hc/ja/articles/40851241011225)」（記事番号01043）で標準機能による方法が案内されていることを確認しました。ご指摘ありがとうございました。

**なぜ出せるのか**

kintone は日付を UNIX 時刻（1970年1月1日＝**木曜日**からの経過秒数）で扱っています。そのため、経過日数を 7 で割った余りで曜日が決まります。余りが 0 なら木曜、1 なら金曜、2 なら土曜、3 なら日曜、4 なら月曜、5 なら火曜、6 なら水曜です。これを `IF` で振り分ければ、**プラグインも JavaScript も使わずに曜日を表示できます**。

`DATE_FORMAT` に曜日を返す書式が無いことは事実で、`"E"` はそのまま表示され、`"ddd"` は `dd`+`d` に分解されて誤った値になります。ここを「曜日そのものが出せない」と書いてしまったのが誤りでした。表の記載は訂正済みです。

**追加したレシピ**

- **日付から曜日を出す** — 日付フィールド／日時フィールドのどちらにも対応。表記は「水」「水曜」「水曜日」「Wed」「2026/04/01（水）」から選べます
- **土日かどうかを判定する** — 土日なら「休」、平日なら「平日」のように表示します（祝日は判定できません）

いずれも**文字列（1行）フィールドの自動計算**に設定します。計算フィールドに入れると、エラーも出ずに空欄になります。

**同じ種類の誤りがないか、サイト全体を点検しました**

「この関数ではできない」と「標準機能ではできない」を混同していないか、公開中の記事とツールを見直したところ、**同じ誤りがもう4件見つかりました**。あわせて訂正しています。

- **年度（4月始まり）・月末日・和暦は出せます**（Shiki に「2段構え（下ごしらえ）」のレシピを4本追加）。`DATE_FORMAT` を式の中に混ぜると空欄になりますが、**単独で計算フィールド（表示形式：数値）に置けば数値として取り出せ**、別の式から参照できます
- **代理承認は kintone 標準でできます**（[承認フローのプラグイン比較](/blog/kintone-shonin-flow-plugin-hikaku/)）。プロセス管理の［作業者以外でも実行できるアクション］の設定です。作業者ではないユーザーで実行できることを実機で確認しました
- **一覧に件数は出ます**（[レコード一覧](/blog/kintone-record-list/)ほか2記事）。出ないのは合計・平均などで、件数はページャーに「1 - 20（123件中）」と表示されます
- **キーワード検索は複数フィールドを横断します**（[検索プラグイン比較](/blog/kintone-kensaku-plugin-hikaku/)）。対象が文字列系フィールドに限られる、というのが正しい制約です
- **通知に独自の文言を足せます**（[メール送信の比較](/blog/kintone-mail-soushin-hikaku/)）。レコードの条件通知の［通知内容］が件名に挿入されます

**実機での確認**

追加した式は、検証用の kintone アプリで 86 通りの値を確認しました。7日連続の日付、うるう年（2024/2/28〜3/1）、年またぎ、1969年・2100年、日時フィールドの日本時間の日またぎ（UTC 14:59 と 15:00）まで、すべて暦どおりです。公式 FAQ の式も同じ検証アプリで通しています。

なお、アプリの「高度な設定 → 数値の有効桁数と丸めかた」で**小数部の桁数を 0 にすると誤った曜日が出ます**（こちらも実機で確認）。既定の 4 のままであれば問題ありません。
