コメントを多用する業務のための新プラグイン「**コメントコントロール for kintone**」v1.0.0 を公開しました。レコード詳細・編集ではコメント欄を閉じて画面を広く使い、一覧ではコメントの状況をひと目で把握。自分宛メンションの見逃しを防ぎます。コメントの取得・表示はすべて kintone 内で行い、外部サーバー・APIキーは不要です。

## 主な機能

- **サイドバーを閉じた状態で開く** — レコード詳細・編集でコメント／変更履歴サイドバーを閉じて表示し、本文を広く使えます。「常に閉じる」／「条件付き開閉（コメントが1件でもあれば開く・自分宛メンションがある時だけ開く）」を選択可
- **チラつき防止** — 閉じるべきレコードでは、開いた瞬間からコメント欄が表示されません
- **一覧コメント件数バッジの色分け** — kintone 標準のコメント件数バッジを流用し、自分宛メンションのあるレコードだけをアクセント色に（独自バッジを足さず二重表示にしません）
- **コメント全文ツールチップ＋ページ送り** — 件数バッジのホバーでコメントを新しい順にプレビュー。10件を超えても「← 前へ／次へ →」で読み進められ、自分宛の行は強調表示
- **配色のカスタマイズ** — 自分宛アクセント色（プリセット8色＋カラーピッカー）と、ツールチップの配色テーマ（ダーク／ライト／ネイビー／カスタム・文字色は自動調整）を設定可能
- **kintone 完結・外部送信なし** — コメントの取得・表示は REST API で行い、業務データを外部へ送信しません

「閉じてすっきり、自分宛は見逃さない」を1つのプラグインで実現します。
