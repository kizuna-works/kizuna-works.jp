kintone プラグイン **[チャット通知 for kintone](/plugins/chat-notify/)** を **v2.2.0** にアップデートしました。

## Chatwork に対応しました

これまでの Slack / Microsoft Teams / Google Chat / LINE WORKS に加えて、**Chatwork** のグループチャットへ通知を送れるようになりました。

送信先に**ルーム**（ルームID またはルームの URL）と **API トークン**を登録するだけです。設定画面に、トークンとルームID の取得方法も表示します。

- API トークンは、プラグインの外部連携の設定（アプリ管理者だけが扱える領域）に保存します。レコード画面からは参照できません
- 組織の設定によっては、API の利用に組織管理者の承認が必要です
- 通知は、トークンを発行したユーザーの名前で投稿されます。通知専用のユーザーをおすすめします

## 全員メンションと見出し付きの枠

**全員メンション**（[toall]）に対応しました。条件を絞った重要な通知にお使いください。ルームの管理者でないユーザーのトークンでは使えない場合があります。

本文は**見出し付きの枠**で表示できます。見出しはルールごとに入り切りでき、空欄ならアプリ名になります。テンプレートに `[To:アカウントID]` と書けば、個人宛ての通知にもできます。

## 更新の手順

最新バージョン（v2.2.0）を製品ページからダウンロードし、kintone のシステム管理 → プラグインから上書きアップロードしてください。保存済みの設定はそのまま引き継がれます。
