kintone プラグイン **[条件分岐フォーム for kintone](/plugins/conditional-form/)** を **v3.0.0** にアップデートしました。

## ルール・チェックを一時的に止められます

各ルール・実行時チェックのカードに［有効］を追加しました。オフにすると、設定を残したまま、そのルール／チェックだけ動かなくなります。

- ほかの JavaScript カスタマイズやプラグインとの競合の切り分け、ちょっとした動作確認に使えます。
- 停止中のカードは灰色になり、「停止中」と表示されます。
- ルール・チェックが 2 件以上あるときは、一覧の上に［すべて停止］［すべて再開］と「停止中 N 件」が出ます。
- 既存の設定はすべて有効のままです。

## 適用しないユーザーを指定できます

ルール・チェックごとに、対象ユーザーとは別の「対象外ユーザー」（橙色の欄）で、適用しないユーザー・組織・グループを選べます。対象外のユーザーには、そのルールは無いものとして扱い、「表示する」の項目もフォームどおり表示されます。

たとえば、一般ユーザーには項目を隠し、システム管理者はチェックのためにすべて見られるようにできます。対象と対象外の両方に当てはまるときは、対象外が優先です。

## 実行時チェックの対象ユーザーの動作を改善しました

実行時チェックの対象ユーザーを組織・グループだけで指定したときも、チェックが働くようにしました。

## 非表示にした項目のふるまいを明記しました

非表示にした項目は、見た目が隠れるだけで、値は残ります。隠れた項目を参照する計算フィールドは再計算されて保存され、CSV 出力などにも値が出ます。詳しくは製品ページの注意事項をご覧ください。

## 更新の手順

最新版を kintone システム管理 →「プラグイン」→「読み込む」から上書きアップロードしてください。**保存済みの設定はそのまま引き継がれます。**
