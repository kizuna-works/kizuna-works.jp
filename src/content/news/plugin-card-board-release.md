レコード一覧を「**状態カード（上部）＋詳細カード（下部）」の2段カンバン**に切り替える新プラグイン「**カードボード for kintone**」v1.0.0 を公開しました。標準の表形式一覧では状態別の進捗が掴みづらく、ステータス変更も1件ずつ詳細画面で行う必要がありますが、本プラグインは**詳細カードを状態カードへドラッグ&ドロップするだけでステータス・選択肢・文字列の値を変更**でき、状態別の件数や合計を一目で俯瞰できます。「プレミアムプラグイン」シリーズの一つです。

## 主な機能

- **2段カンバン表示** — 上部に状態カード（状態名＋件数＋集計値）、下部に詳細カードを並べ、状態別の分布を全幅で俯瞰
- **ドラッグ&ドロップで値変更** — 詳細カードを状態カードへドロップして、ステータス・ドロップダウン・ラジオ・文字列の値を変更。プロセス管理は遷移制約に準拠し、次の作業者の自動判定・選択モーダルにも対応
- **状態カードの集計値** — その状態に属するレコードの合計・平均・最大・最小・件数を算出して表示（例：申込あり／3件／家賃計732,000円）
- **連動 / 個別モード** — 全レーンを横並びで俯瞰する「連動（カンバン）」と、1状態を画像つきギャラリーで見る「個別」を切替。レーンの区切り線・初期に開く状態も指定可能
- **添付サムネイル** — 詳細カードに添付ファイルの画像をサムネイル表示（配置・表示方法・サイズ・背景色を指定）。物件・商品・名簿を写真つきカードで共有
- **絞り込み・並び順に連動** — 対象一覧の絞り込み条件・並び順がそのまま反映され、状態カードの件数・集計も絞り込み後で再計算
- **ライブプレビュー設定** — 実レコードを使ったプレビュー付き設定。複数の一覧ビューへ保存・適用（プレミアム）
- **kintone 完結** — レコードの取得・変更・サムネイル取得はすべて自ドメインの kintone REST API で完結。業務データを外部へ送信しません

## ご利用プラン

無料プランでも**1つの一覧ビューで全機能**（状態カード・詳細カード・D&D・連動/個別モード）をお試しいただけます。**複数ビューへの適用**と広告非表示は、**プレミアム年間サポーター**（年額 ¥16,500・税込）で解放され、販売中の全プラグインも利用できます。
