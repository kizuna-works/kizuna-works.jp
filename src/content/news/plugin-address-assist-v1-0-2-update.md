kintone プラグイン「住所アシスト for kintone」を **v1.0.2** にアップデートしました。今回の対応で、**ゲストスペース内のアプリ**でもご利用いただけるようになりました。

## ゲストスペースに対応しました

これまでは、ゲストスペース内のアプリで設定画面のフィールド選択や地図プレビューが正しく動作しないことがありました。v1.0.2 では、フォーム情報を取得する内部の API 呼び出しをゲストスペース用の通信経路に対応させ、**ゲストスペース内のアプリでも設定・動作ができる**ようになりました。

- 設定画面で郵便番号フィールド・住所フィールド・地図プレビューの表示先スペースを選択できます。
- レコード画面での住所自動入力・Google マップ URL 生成・地図プレビュー・住所コピーが、ゲストスペースでも従来どおり動作します。

社外の方とやり取りするゲストスペースで、住所入力と地図確認をまとめて行いたい場合にお使いいただけます。

## 既存ユーザーへの影響

通常スペースでの使い方・挙動はこれまでと変わりません。最新版（v1.0.2）をダウンロードし、kintone のシステム管理 → プラグインから上書きアップロードするだけで適用できます。設定の再登録は不要です。

[住所アシスト プラグインページを見る →](/plugins/address-assist/)
