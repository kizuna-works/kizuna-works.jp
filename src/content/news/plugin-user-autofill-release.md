担当者を選ぶだけで情報が埋まる新プラグイン「**ユーザーオートフィル for kintone**」v1.0.0 を公開しました。日報・申請書・購買フローなど、ユーザーに紐づく情報を扱う業務の入力をまとめて自動化します。取得はすべて kintone 内で行い、外部サーバー・APIキーは不要です。

## 主な機能

- **属性の自動転記** — ユーザー選択フィールドで選んだ人（新規作成時は自分）の組織・グループ・役職・メール・電話・社員番号・ふりがな・生年月日・入社日・カスタマイズ項目を、対応フィールドへ自動でセット
- **組織・グループは選択値でセット** — 優先する組織は「組織選択」、所属グループは「グループ選択」フィールドへ選択値として入れるので、表記ゆれなく集計・絞り込みに使えます（除外グループ指定可）
- **新規作成時に自分を自動セット** — 新規作成画面で起点フィールドが空なら、ログインユーザーを自動セットして転記。「報告者＝自分」「所属＝自分の部署」の入力が不要に
- **上書きポリシー** — マッピングごとに「空のときのみ／常に上書き」を選択
- **プロフィールカード表示** — 選ばれた人の画像＋氏名・所属（営業部 営業一課のような親階層）・役職・社員番号などを、フォーム上のスペースにカード表示（フィールドごとに複数配置可・配色／フォント／形状を設定可）
- **捺印（承認欄）モード** — 1つのスペースに申請者・承認者・最終承認者などのフィールド名を横並びにし、各ユーザーの姓を朱色の印（決裁欄）として表示。漢字の姓は縦書き
- **転記と表示は独立** — 「転記設定」「ユーザー情報表示」の2タブで、どちらか一方でも両方でも利用可能
- **kintone 完結・外部送信なし** — 取得は kintone の JavaScript API を優先し、業務データを外部へ送信しません

「選んだら、ぜんぶ埋まる」をコンセプトに、ユーザー情報まわりの入力・表示を一気に効率化します。
