kintone プラグイン **[カレンダービュー for kintone](/plugins/calendar-view/)** を **v2.7.0** にアップデートしました。

## 予定の削除のしかたを選べます

カレンダー上の削除は kintone の REST API で行うため、kintone の仕様で、アプリに設定した Webhook（レコードの削除）が送られません。

設定「7 編集と動作」の「予定の削除」で、「kintone 標準のレコード詳細画面を開いて削除する」を選ぶと、モーダルの［削除］や右クリックの［削除する］で確認のあと詳細画面が開きます。詳細画面で削除すると、Webhook がそのまま送られます。既定は、これまでどおりカレンダー上で削除します。

## カレンダー上で削除したときに、指定した URL へ削除の通知を送れます

「削除の通知」をオンにして URL（https・10 件まで）を登録すると、kintone の Webhook「レコードの削除」と同じ形の JSON を送ります。1 件ずつの削除、繰り返し予定の削除、［元に戻す］による作成・複製の取り消しが対象です。送れなかったときは、警告を 1 回表示します。既定はオフです。

## 更新の手順

最新バージョンを kintone システム管理 →「プラグイン」→「読み込む」から上書きアップロードしてください。プラグインIDは変わらないため、**各アプリに保存済みの設定はそのまま引き継がれます**。
