KIZUNA Works の kintone プラグイン 15 製品をアップデートし、**kintone の API リクエスト数を節約する対策**を講じました。設定・画面の見た目は変わりません（フォーム連携の自動取り込みの間隔と、メールアシストの送信履歴の欄の表示が変わります。下記）。

## 何が変わったか

kintone には、**1 つのアプリで 1 日に実行できる API リクエスト数**の上限があります（スタンダードコースは 10,000 件）。プラグインがアプリの設定（フィールドやレイアウトの情報）を読むときに使う通信もこの数に含まれます。

これまで、以下のプラグインは一覧・詳細・編集の画面を開くたびに、この情報を API で取り直していました。今回のアップデートで、kintone が画面にすでに持っている情報を使うように変え、**画面を開くだけでは API リクエストを使わない**ようにしました。

**あいまい照合**（10 月 4 日追加）は、新規作成・編集の画面を開くたびに、照合に使う既存のレコードを全件取得していました。取得した値をお使いのブラウザに控え、2 回目以降は前回以降に更新されたレコードだけを取るように変えました。1,000 件を超えるアプリでも開くたびの取得は 2 回で済み、照合する欄に入力しなければ 0 回です。控えるのは照合と参照表示に使うフィールドの値だけで、ログインしている人ごとに分けて最大 12 時間で破棄します。外部へ送ることはありません。

**フォーム連携**（10 月 4 日追加）は、一覧を開くたびに（ページ送りや並べ替えのたびにも）自動取り込みを実行し、新しい回答が無くても照合のための API リクエストを使っていました。**自動取り込みは前回から 5 分以上たっているときだけ**動くように変えました。連携フォーム 2 本のアプリで測ったところ、一覧を開くたびの 6 回が、5 分以内は 0 回になりました。新しい回答が一覧に出るまで最大 5 分かかることがありますが、すぐに取り込みたいときは一覧の［取り込む］ボタンがいつでも使えます。

**メールアシスト**（10 月 4 日追加）は、テンプレート保管アプリのテンプレートを一覧・詳細を開くたびに取り直し、詳細画面では送信履歴も毎回 2 回取得していました。テンプレートはお使いのタブに 10 分間控えるようにし、**詳細画面の「メール送信履歴」の欄は［表示する］を押したときだけ読み込む折りたたみ式**に変えました。一度開くと次からも開いた状態で表示されます。詳細を開くたびの 3 回が、履歴の欄を閉じていれば 0 回になります。保管アプリでテンプレートを直した内容は、最大 10 分遅れて反映されます。

レコード数が多く、たくさんの人が一日中使うアプリでは、この通信が積み重なって上限に近づくことがあります。実際のアプリで測ったところ、1 件の案件を「一覧 → 詳細 → 編集 → 保存後の詳細」と操作したときの API リクエスト数が、**約 27 件から約 6 件**に減りました（残りは他のプラグインやカスタマイズによるものです）。

## アップデートの方法

各製品ページから最新版をダウンロードし、kintone の「kintone システム管理」→「プラグイン」で**上書きで読み込んで**ください。アプリに保存した設定はそのまま引き継がれ、設定のやり直しは不要です。

「1 日の API リクエスト数」は、kintone システム管理の「アプリ管理」で、アプリごとに確認できます。上限に近いアプリでお使いの場合は、早めの上書きをおすすめします。

[プラグイン一覧を見る →](/plugins/)
