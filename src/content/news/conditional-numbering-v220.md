kintone プラグイン「**条件分岐自動採番 for kintone**」を **v2.2.0** にアップデートしました。

## ルックアップ新規登録の中でも採番されます

同日に公開した[ルックアップ新規登録](/plugins/lookup-add/)は、ルックアップの［取得］の隣から**参照先アプリのレコードをその場で登録**できるプラグインです。この登録は kintone の REST API で行うため、これまでは**参照先アプリ側の採番が動きませんでした**（保存時の処理を通らないため）。

v2.2.0 では、条件分岐自動採番が**採番の窓口を公開**し、ルックアップ新規登録の登録パネルから呼び出せるようにしました。参照先アプリ側に本プラグインを入れておけば、次のように動きます。

- 登録パネルで、採番対象の項目は**入力欄を出さず「自動採番」とだけ表示**します
- ［登録］を押した瞬間に本プラグインが番号を発行し、その番号で登録します
- 採番できないときは**登録を中止**して、やり直しと標準画面方式への切り替えを案内します（**採番されないまま登録されることはありません**）

条件分岐（区分ごとに別の系列で採番する、日付を含める、など）の設定はこれまでどおり働きます。**採番の仕様そのものは変更していません。**

## 連携には v2.2.0 以上が必要です

ルックアップ新規登録と組み合わせる場合は、**参照先アプリ側の条件分岐自動採番を v2.2.0 以上**にしてください。v2.1.1 以前では窓口がないため連携できず、ルックアップ新規登録の設定画面が警告を表示します。

連携を使わない場合は、これまでどおりの動作です。アップデートは必須ではありませんが、**v2.1.1 以前からの改善（イベントの保護・要望フォームの入力補助）も含みます**ので、更新をおすすめします。

更新は、新しい zip を同じ手順で読み込むだけです（kintoneシステム管理 → プラグイン → 読み込む）。**アプリごとの設定は保持されます。**
