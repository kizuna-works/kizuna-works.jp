kintone のプラグインは自動更新されません。新しい版を公開しても、管理者が自分で上書きアップロードするまで古い版が使われ続けます。これまで更新のお知らせは各プラグインの設定画面サイドバーだけだったため、設定画面を開かない限り、不具合修正版が出ていても気づけませんでした。

Chrome 拡張機能「KW Plugin Updater for kintone」は、kintone を開くだけで導入済みの KIZUNA Works プラグインの版を照合し、更新できるものをツールバーのバッジ・通知・プラグイン管理画面の印で知らせます。

- 更新できる件数をツールバーのバッジに表示。アイコンをクリックすると「現在の版 → 最新版」の形で一覧表示します
- 一覧のボタンから最新版 ZIP を直接ダウンロードできます
- プラグイン管理画面の該当行に「更新あり → 最新版」のバッジを表示。上書きアップロードを検知して自動で再チェックします
- 未導入の「おすすめ」「新着」プラグインもポップアップから確認できます
- 導入済みプラグインの一覧・ドメイン名・レコード値は外部に送信しません（照合は端末内で完結）

完全無料・ゲストスペース対応です。
