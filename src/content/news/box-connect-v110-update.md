kintone プラグイン「**Box連携 for kintone**」を **v1.1.0** にアップデートしました。

## 今回のアップデート内容

- **添付ファイルが無くても、レコードごとのフォルダを先に作れるようになりました** — 自動転送のルールで「添付ファイルが無いとき：フォルダだけ作成する」を選ぶと、添付が無いレコードでも、詳細画面を開いたときに Box のフォルダを作り、リンクフィールドに書き込みます（共有リンクの設定があれば共有リンクも）。リンクフィールドに値があるレコードでは何もしないので、フォルダは重複しません。あとからファイルを入れていく運用に使えます（自動転送はプレミアムの機能です）
- **フォルダの中身の表示を改善しました** — 「表示するフォルダ」に共有リンクが入る欄を選んでいても、フォルダの中身を表示できます。選んだ欄がフォルダの URL でないときは、原因が分かる案内を出します

なお、フォルダは詳細画面を開いたときに作られるため、CSV 読み込みや API など画面を通さずに登録したレコードは、詳細画面を開くまで作られません。

## 既存ユーザーの方へ

これまでの設定はそのまま引き継がれます。最新版（v1.1.0）をダウンロードして、kintone の**システム管理 → プラグイン**から上書きアップロードしてください。
