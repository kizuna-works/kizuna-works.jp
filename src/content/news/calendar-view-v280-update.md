kintone プラグイン **[カレンダービュー for kintone](/plugins/calendar-view/)** を **v2.8.0** にアップデートしました。同じ日に公開した v2.7.0 の内容も、あわせてご紹介します。

## 1つの設定を、複数の一覧で使えます（v2.8.0）

手順1「ビューを作る」の「同じ設定で表示する一覧（追加）」で一覧を選ぶと、選んだ一覧に同じカレンダーが表示されます。その場で新しい一覧を作ることもできます。

表示されるレコードは、それぞれの一覧の絞り込み条件で決まります。たとえば、全員の予定を出す一覧と、「ユーザー選択」が「ログインユーザー」の一覧（自分の予定だけ）を、設定1つで使い分けられます。絞り込みだけを変えたいときに、同じ設定を二重に管理する必要はありません。

## 設定を丸ごと複製できます（v2.8.0）

［この設定を複製］を押すと、いまの設定をそのままコピーした新しい設定「〇〇のコピー」ができます。描画先の一覧を選んで保存すれば、すぐに使えます。

## モバイルでの一覧の絞り込みと、繰り返し予定の編集・削除を改善しました（v2.8.0）

モバイルでも、一覧の絞り込み条件がカレンダーに反映されます。複数の設定を使っているときも、詳細画面から「この予定以降」を選んだ編集・削除が、系列の他の予定に反映されます。

## 予定の削除のしかたを選べます（v2.7.0）

カレンダー上の削除は kintone の REST API で行うため、kintone の仕様で、アプリに設定した Webhook（レコードの削除）が送られません。

設定「7 編集と動作」の「予定の削除」で、「kintone 標準のレコード詳細画面を開いて削除する」を選ぶと、モーダルの［削除］や右クリックの［削除する］で確認のあと詳細画面が開きます。詳細画面で削除すると、Webhook がそのまま送られます。既定は、これまでどおりカレンダー上で削除します。

## カレンダー上で削除したときに、指定した URL へ削除の通知を送れます（v2.7.0）

「削除の通知」をオンにして URL（https・10 件まで）を登録すると、kintone の Webhook「レコードの削除」と同じ形の JSON を送ります。1 件ずつの削除、繰り返し予定の削除、［元に戻す］による作成・複製の取り消しが対象です。送れなかったときは、警告を 1 回表示します。既定はオフです。

## 更新の手順

最新バージョンを kintone システム管理 →「プラグイン」→「読み込む」から上書きアップロードしてください。プラグインIDは変わらないため、**各アプリに保存済みの設定はそのまま引き継がれます**。
