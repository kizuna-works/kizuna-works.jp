kintone プラグイン「**アコーディオンタブ for kintone**」を **v2.0.0** にアップデートしました。長いフォームを見出しで折りたたむ機能はそのままに、**セクション（見出し）ごとの表示制御**を追加しました。

## 今回のアップデート内容

- **セクションごとの閲覧制限** — セクションごとに閲覧できる**ユーザー・組織・グループ**を指定できます。対象外の人には見出しを**ロック表示（開けない）**にするか、**セクションごと非表示**にできます
- **セクションごとのパスワード** — セクションごとに**パスワード**を設定し、正しいパスワードを入力すると開くように制御できます（開いた状態はそのレコードを表示している間だけ保持）
- **詳細・新規作成・編集画面で有効** — 制限したセクション内に必須項目があると保存を妨げる場合があるため、設定時に確認メッセージを表示します

担当や役割ごとに、同じアプリの中でも見せたい情報だけを出し分けられます。

> ※ これは画面上の**簡易的な表示・開閉のコントロール**であり、kintone 標準のアクセス権のような機密保護ではありません（レコードのデータ自体は API などから取得可能です）。機密情報の保護には kintone 標準の「フィールド／レコードのアクセス権」を併用してください。

## 既存ユーザーの方へ

最新版（v2.0.0）をダウンロードし、kintone のシステム管理 → プラグインから**上書きアップロード**するだけで適用できます。設定はそのまま引き継がれます。
