レコード保存のたびに**フィールド単位で変更前後の値・変更者・日時を自動記録**し、レコード詳細画面に時系列の表形式で表示する新プラグイン「**クイック履歴ビュー for kintone**」v1.0.0 を公開しました。GAS や外部サービスは不要、**kintone 内で完結**する手軽な変更履歴ソリューションです。

## 主な機能

- **変更前後の自動記録** — レコード保存時に対象フィールドを比較し、差分があったものだけを履歴 JSON に追記。日時・変更者も自動付与
- **レコード詳細画面に表形式で表示** — 設定したスペース要素に「日時・変更者・フィールド・変更前・変更後」の 5 カラムテーブルで時系列降順に表示
- **新規作成時の初回スナップショット** — 新規レコードの保存時、入力済みフィールドを「変更前: 空 / 変更後: 入力値」として初回履歴に記録
- **記録対象フィールドの選択** — 左右の転送リスト UI で対象 / 除外を直感的に切替。デフォルト全フィールド対象
- **保存件数上限**（5・10・20・30件） — 上限超過時は古い履歴から自動削除
- **表示デザインのカスタマイズ** — ヘッダー色・行色・文字色を個別指定、10 種類の日本語フォント＋ 3 段階の文字サイズ
- **リアルタイムプレビュー付き設定画面** — 色・フォントを変更すると即時プレビューに反映
- **履歴保存フィールドの自動非表示** — レコード詳細・編集・新規作成画面で自動非表示

「いつ誰が何を変えたか分からない」「変更履歴の自作は手間」「外部サービスに依存したくない」といった声に、kintone 完結で応えられます。
